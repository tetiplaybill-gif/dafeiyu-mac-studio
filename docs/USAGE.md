# 互动、计时与直播声音

## 评论与欢迎

评论回复默认至少间隔 8 秒，等待上一条播报完成。最多等待 10 条，超过 45 秒的评论过期；同一观众 30 秒内的重复内容略过。暂停后不补播暂停期间的消息。

进场欢迎由带用户 ID 和昵称的真实 `WebcastMemberMessage`（action=1）触发，不把在线人数变化当作个人进场。欢迎称呼固定为“新来的朋友”，实际昵称只在本机列表显示，避免特殊字体/数字昵称影响语音转录校验。

同一人 5 分钟内不重复欢迎，欢迎语至少间隔 20 秒，最多等待 5 人、等待上限 30 秒。评论优先于欢迎，进行中的语音和舞台动作不会被欢迎打断。

## 空闲小动作

默认中心间隔 45 秒，实际随机间隔约 30～60 秒；中心间隔可设置为 30～180 秒。使用现有短动画，避免连续重复，忙碌时重新等待。此功能不调用模型、不生成语音。

## 礼物与倒计时

默认倒计时 60 分钟，需点击开始；可暂停或重设。到时只提醒，不会关闭平台直播。暂停或到时后收到礼物增加余额，需要手动开始计时。

| 礼物 | 每份默认加时 | 动作 |
| --- | ---: | --- |
| 人气票 | 30 秒 | 偷吃 |
| 小心心 | 60 秒 | 节奏舞 |
| 玫瑰 | 90 秒 | 舞台走位 |
| 大啤酒 | 180 秒 | 节奏舞 |
| 棒棒糖 | 120 秒 | 舞台走位 |
| 鲜花 | 60 秒 | 舞台走位 |
| 加油鸭 | 300 秒 | 节奏舞 |
| 爱你哟 | 300 秒 | 节奏舞 |

可在工作台修改上述规则。未配置名称的礼物感谢并庆祝，但加时为 0；总剩余时间上限 24 小时。舞蹈/走位由原动画加整体移动实现，不是新增角色骨骼或独立迈腿动作。

礼物在工作台接收成功时计入数量与加时，随后排队执行感谢和动作；语音失败或停止播放不会撤销已计入的时间。采集器等待工作台空闲再转交，礼物优先于评论和欢迎。

同一连送组按累计值的新增部分计算，不累加每条进度包。结束包、重复累计和倒序消息不会再次加时。快速更新合并约 1.5 秒；结束标志使该组立即可处理。计数依据为 `repeatCount`（缺失时用 `comboCount`）乘 `groupCount`，出现计数冲突或缺少连送组时暂停该项，显示待核对。

**当前尚未完成真实礼物端到端验收。** 计数、去重和加时已通过合成协议与隔离工作台测试，不能替代你的真实平台数据验证。若平台显示收礼而采集为零，请在采集 Chrome 窗口正常登录后重连；不要导出 Cookie。

礼物去重记录位于 `out/macos/gift-ledger.json`，保存分组哈希和累计值，保留 24 小时、最多一万组。不要在直播中删除。无法读写记录时停止礼物转交。未知提交结果不自动重试；为防重复加时，进程退出或用户停止采集后可能不会补回尚未完成转交的数量。短暂 WebSocket 断线保留尚未提交的队列，等待连接恢复；礼物队列上限 100 组、等待上限 10 分钟。

首次连接的首批/前 4 秒数据、旧消息不会自动补计。平台网页和消息格式可能变化，不保证完整收到所有事件。主舞台总数包含排练；采集面板单独统计实际收到的来源事件，不等于平台收入。

## 模型与语音

文字对话使用 OpenAI Responses；自然语音使用原生 Swift URLSession WebSocket。已有的台词生成完整音频后，校验转录与台词，再由 Mac 播放。转录不符、鉴权、额度或连接失败会显示错误，不暗中切换音色或反复重试。

密钥只在主进程内存保存。刷新网页不丢失，重启主程序会清除。仅重启采集器不会清除主程序密钥、倒计时或规则。分享故障信息时不要包含密钥或服务响应原文。

## 推流与观众端声音

纯净画面在 <http://127.0.0.1:18766/stage>，可作为 OBS 的浏览器画面。音频由运行 Python 主服务的 Mac 播放，并不从网页音轨输出；需要在 OBS/直播软件中采集相应应用或系统声音。虚拟摄像头只传画面。

打开多个预览不会重复播放音频。采集 Chrome 保持静音以避免直播声音回授。请用观众设备确认最终声音和画面，本机播放成功不能证明观众听到。

## 文件与入口

- `tools/mac_studio.py`：本机 18766 工作台、模型/语音队列和事件接口。
- `tools/mac_danmaku.cjs`：本机 18768 采集器、Chrome 消息观察和互动调度。
- `tools/gift_policy.cjs`：礼物累计转增量与持久化去重。
- `tools/host_activity.cjs`：欢迎节流和空闲动作。
- `Live2D/macos/`：舞台与控制面板。
- `out/macos/`：运行时音频、浏览器会话、编译产物和去重记录，禁止公开。

服务只允许本机来源访问，不应端口映射到公网。源码中的 `/send` 接口兼容 comment、entrance、gift；外部适配器必须提供稳定 `event_id`，礼物数量应是本次新增数量而非累计连击数。
